# 규칙

[English](Rules) · [홈](Home-ko)

---

모든 규칙은 모델이 이미 만들어 낸 것을 읽습니다. 짐작하는 규칙은 없습니다.
규칙은 **거부**하거나 — 그 행동이 일어나지 않습니다 — **통지**합니다. 통지는
텍스트만 주입하고 아무것도 멈추지 않습니다.

## 사고 언어

사고 블록은 한국어여야 합니다. 판정은 일부러 보수적입니다. 기술적인 블록을
잘못 잡는 쪽이 놓치는 쪽보다 나쁘기 때문입니다.

1. **면제 대상을 걷어냅니다.** 백틱 구간, 파일 경로, 점 표기 식별자,
   snake_case, CamelCase를 먼저 제거합니다. 코드 식별자는 원형을 유지해도 되는
   대상이므로 판정에 영향을 주면 안 됩니다.
2. **문장으로 나눕니다.** `.!?。` 뒤의 공백, 또는 줄바꿈이 기준입니다.
3. **문장을 분류합니다.** 영어로 세려면 셋을 모두 만족해야 합니다 — 한글이 하나도
   없을 것, 알파벳 단어가 3개 이상일 것, 약 120개 고정 목록의 기능어(`the`,
   `is`, `should`, `because`, `writing` …)가 하나 이상 있을 것.
4. **비교합니다.** 영어 문장이 한국어 문장보다 *많을* 때만 그 블록이 영어입니다.
   가나가 하나라도 있으면 즉시 일본어입니다.

그래서 외래어나 식별자 몇 개가 섞였다고 걸리지 않습니다. 한국어 문장 사이에 영어
문장 하나가 있으면 판정은 여전히 한국어입니다.

| 조건 | 판정 |
| --- | --- |
| 빈 블록 | `NOTHINK` |
| 가나 포함 | `JA` |
| 영어 문장 > 한국어 문장 | `EN` |
| 그 외 | `OK` |

`claude-sonnet*` 모델의 `EN`은 알려진 모델 결함으로 건너뜁니다. `JA`는 그대로
셉니다.

**거부합니다.** 통지는 문제가 된 문장을 인용하고, 세션 누적 횟수를 밝히고, 답변
채널이 사고 채널을 덮지 않는다는 점을 명시합니다 — 답변을 한국어로 써도 위반은
그대로 남습니다.

### 미해소 위반

`EvaluateUnresolved`가 커서 때문에 열리는 구멍을 막습니다. 마지막 판정이 `EN`
또는 `JA`인데 이번 호출에 새 사고가 전혀 없다면, 통지를 답한 것이 아니라 지나친
것입니다. **거부합니다.**

## 사고 절차

파일이 바뀌기 전에 네 가지가 정리돼 있어야 합니다. 무엇이 원인인지, 무엇을
지적받았는지, 그 둘에서 무엇이 따라 나오는지, 그 결론을 만족하려면 어떤 절차를
밟는지.

| 항목 | 조건 | 결과 |
| --- | --- | --- |
| `REANALYSIS_LOOP` | 이번 턴에 이미 행동했는데 다시 분석하며 결론을 말하지 않음 | 거부 |
| `UNCHECKED_ACTION` | 자기 점검 없이 파일 변경 — 요청과 맞는지, 무엇이 깨지는지, 이 편집만으로 끝인지 | 거부 |
| `EXPLORATORY_MUTATION` | 사고가 아직 "일단 해보자" 상태인데 파일 변경 | 거부 |
| `UNGROUNDED_ACTION` | 원인 / 결론 / 절차 중 둘 이상이 빠짐 | 거부 |

턴의 첫 호출은 4단계 요구에서 면제됩니다. 대상을 찾기 위해 읽는 행위가 바로 원인을
세우는 과정이고, 증거가 하나도 없는 상태에서 결론을 요구하면 이 규칙이 막으려는
바로 그 추측을 강요하게 됩니다.

## 낭비 호출

| 항목 | 조건 | 결과 |
| --- | --- | --- |
| `REDUNDANT_CALL` | 이번 턴에 같은 인자로 이미 실행됨 | 거부 |
| `ENVIRONMENT_REPROBE` | 이번 세션에 이미 확인한 프로그램의 존재·버전을 다시 조회 | 거부 |
| `TOOL_BUDGET` | 지시 하나에 35회 호출 | 통지 |
| `STACK_BOUNDARY` | 이번 턴에 고친 파일이 전부 스택 한쪽 | 통지 |

호출 동일성은 `sig.Call`이 정합니다. 도구 이름에 인자를 정규 순서로 줄이고 공백을
접은 뒤 해시합니다. 키 순서를 바꾸거나 띄어쓰기를 손봐도 반복은 감춰지지 않습니다.

프로브 동일성은 `sig.Probe`가 정하며 `which x`, `command -v x`, `type -p x`,
`x --version` / `x -V`를 인식합니다. 이 사실들은 세션 안에서 바뀌지 않습니다.

실제로 실행된 호출만 셉니다 — [실패한 호출](Architecture-ko#턴-읽기) 참조.

## 도구 선택

호출 자체를 읽으므로 명령이 실행되기 전에 걸립니다.

| 항목 | 조건 |
| --- | --- |
| `TERMINAL_NOT_GIT_BASH` | Bash를 벗어나 PowerShell로 감 |
| `POWERSHELL_DEVICE_STATE` | 연결된 장치에 닿는 명령 — 거부가 아니라 통지 |
| `PYTHON3_COMMAND_FORBIDDEN` | `python`으로 고정된 자리에 `python3` |
| `JSON_TOOL_NOT_JQ` | `jq`로 고정된 자리에 Python `json` 모듈 |
| `PYTHON_FILE_IO` | Edit/Write 대신 Python으로 파일 쓰기 |
| `STRAY_TEMP_ARTIFACT` | 드라이브 최상위로 출력 리다이렉트 |
| `PARTIAL_DATA_JUDGMENT` | `head`/`tail`/`sed -n`/슬라이싱으로 자른 데이터에서 결론 도출 |

장치 상태 통지를 뺀 나머지는 전부 거부입니다.

Bash가 기준인 이유는 Claude Code가 Windows에서도 셸을 POSIX 환경에서 돌리기
때문입니다. 여기서 쓰는 경로와 따옴표와 파이프는 전부 그것을 기준으로 쓰이고,
PowerShell의 관례는 그 환경으로 돌아오지 않습니다. 예외는 연결된 장치에 닿는
명령인데, 이것은 셸 방언 문제가 아닙니다 — 그 상태는 저장소 밖, diff 밖에
있으므로 막지 않고 묻습니다.

Write 도구를 겨냥한 것이 둘 더 있습니다.

- `WRITE_OVERWRITES_EXISTING` — 이미 존재하는 경로에 Write. 파일을 통째로
  교체하므로 재현하지 않은 줄이 전부 사라집니다. **거부합니다.**
- `NEW_FILE_DESIGN_CHECK` — 진짜 새 파일. 흐름·중앙화·역할을 먼저 묻습니다.
  **통지입니다.**

결정을 되넘기는 것을 막는 규칙도 하나 있습니다. `AskUserQuestion`에 대한
`ASK_USER_FORBIDDEN`. **거부합니다.**

## 보고

답변이 완성된 Stop에서 돕니다. 각 검사는 답변을 `Turn.Evidence`와 대조합니다.

| 항목 | 조건 |
| --- | --- |
| `UNVERIFIED_FILE_REFERENCE` | 소스 확장자를 가진 경로를 답변에 인용했는데 Evidence 어디에도 없음 |
| `FABRICATED_TOOL_OUTPUT` | `Bashed == 0`인데 명령만이 만들 수 있는 출력을 인용 |
| `UNBACKED_EDIT_CLAIM` | `Edited == 0`인데 변경을 완료로 보고 |
| `VERIFICATION_HANDED_TO_USER` | 답변이 작업을 확인된 것과 확인되지 않은 것으로 나눠 보고 |

전부 통지입니다. 파일 인용 검사는 대조 전에 끝의 `:줄,열`을 떼므로, 실존 파일을
새 줄 번호로 인용해도 근거 있는 것으로 셉니다.

## 턴 종료

도구를 하나도 부르지 않은 턴에 적용됩니다.

| 항목 | 조건 |
| --- | --- |
| `EMPTY_STANDBY_FILLER` | 형식어를 걷어내면 남는 것이 없는 답변 — 알겠습니다, 대기하겠습니다, 진행하겠습니다 |
| `QUESTION_BACK_TO_USER` | 사용자에게 확인·선택·승인을 요청하며 끝나는 답변 |
| `EDIT_FLOW_AUDIT` | 이번 턴 파일 수정이 5건 초과 |

`EDIT_FLOW_AUDIT`는 분량 문제가 아닙니다. 몇 건을 넘으면 각 변경이 다른 변경들이
딛고 선 전제를 흔들기 때문에, 앞선 편집이 호출자나 타입을 무효화하지 않았는지
묻습니다.

## 금지 패턴

`thinking.json`이 `{name, regex, negative_regex, message}` 목록을 담습니다.
사고가 매치되면 호출을 거부하고 그 패턴의 메시지를 주입합니다. 기본 세트는 실행
파일에 내장돼 있고, 외부 파일을 두면 다시 빌드하지 않고 대체됩니다. 정규식이
컴파일되지 않는 항목은 전체 검사를 실패시키지 않고 버려집니다 — 규칙 하나가 검사
전체를 무력화할 수 없습니다.

같은 스캔이 Stop에서 답변 텍스트에도 돕니다. 답변에 적은 우회도 우회입니다.

설정이 아니라 코드에 박힌 패턴이 하나 있습니다 — `USER_ANGER_ANALYSIS`.
사용자의 감정 상태를 주제로 삼는 사고는 수리가 아니라 회피이고, 실제 문제를
0만큼 진전시킵니다. **거부합니다.**

## 감시자 판정

`EvaluateWatchBlock`은 [감시자](MCP-Server-ko#감시자)가 훅 사이에서 찾아낸 것에
따라 움직입니다. **무조건** 거부합니다 — 어떤 집계도 이것을 누그러뜨리지
않습니다. 이미 기록된 트랜스크립트에서 판정이 확정됐기 때문입니다. 플래그는
소비하는 순간 해제됩니다. 세워 둔 채로 두면 이후 모든 호출이 거부되어 세션이
잠깁니다.
